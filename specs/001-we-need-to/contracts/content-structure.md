# Content Structure Contract

## Blog Post Format
- **Title**: H1 with primary keyword
- **Meta Description**: 150-160 characters with keyword
- **Headings**: H2 for sections, H3 for subsections
- **Content**: 1500-2000 words, readable paragraphs
- **Images**: Alt text with keywords, explicit width/height
- **Links**: Internal to products, external to authorities
- **CTAs**: Prominent buttons throughout content

## Validation
- Title keyword density: 1-2%
- Heading hierarchy: Logical structure
- Readability score: >60 Flesch
